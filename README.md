# 海战棋(Battleship)

当前版本：0.0.2

本项目为莆田第一中学第一届3099知识竞赛决赛“海战棋”环节所使用的程序。

> 由于该程序的赶工性和（可能的）单次使用性，其存在大量冗余无用代码与不规范的书写格式，另外还包括极其困难的操作。<s>由于各种原因，作者无法保证继续对其进行维护</s>。
