# 海战棋(Battleship)

当前版本：0.0.2

本项目为莆田第一中学第一届 3099 知识竞赛决赛“海战棋”环节所使用的程序。

> 由于该程序的赶工性和（可能的）单次使用性，其存在大量冗余无用代码与不规范的书写格式，另外还包括极其困难的操作。<s>由于各种原因，作者无法保证继续对其进行维护</s>。

2026.9.13 Update
**作者心血来潮维护了一下子。**

0.0.2 更新：
BUGs
1. 修复了没有题目后仍然可以答题的漏洞。
2. 加强了船位置文件的校验。
3. 修复了加载文件的异步问题。
4. 修复了键盘操作对于已开火格子的重复扣除炮弹问题。

6. 修正了音频文件大小写问题。
7. 修改了结算判定逻辑，题目答完后且双方炮弹都被打完时会触发结算而不是无法继续。

FEATs
1. 新增整题 LaTeX 语法支持，能够出更难的题目了！

3. 新增了地图生成器的随机布局功能。
4. 新增了剩余题数显示。
5. 新增了答题后改选的功能（防止操作者听错答案或者是选错队伍）。

7. 结算功能从自动改为手动点击按钮，方便活动安排。题目全部问完后先收起题目面板；若双方仍有炮弹，需打完后再进入结算（期间仍可能分出胜负，否则暂按平局）。
